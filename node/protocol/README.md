# Protokół node

Ten katalog zawiera bieżący endpoint komunikacyjny firmware. Nazwa katalogu
jest celowo bez numeru wersji: wspólnie obsługuje framing protocol 3 oraz
application protocol 6. Wersje wire należą do `common/protocol_ids.h`,
capabilities, golden vectors i dokumentów kontraktowych, a nie do ścieżki
źródłowej.
