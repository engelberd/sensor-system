# Dokumentacja systemu legacy

Pliki w tym katalogu opisują działający host Python, application protocol 4,
framing protocol 2, dotychczasowe formaty HDF5 albo historyczne rollouty.

Są przydatne jako źródło scenariuszy, pomiarów i zachowań do zachowania. Nie są
specyfikacją `host_v2`, framing protocol 3 ani application protocol 5. Aktualny
plan zaczyna się w [docs/README.md](../README.md).
